# Changelog

All notable changes to the LingXi Global skill. Newest first. Every change to this skill must bump `metadata.version` in `SKILL.md` and add an entry here.

## 1.0.0 — 2026-10-21

- First public release, combining the former forms-and-activities and contacts skills into one skill.
- Session check on first use: connection, organization, permissions and version, using `get_lingxi_status`.
- Step-by-step connection guide for Claude Code, Claude apps and other MCP clients.
- Interaction standards: plain business language, no technical details or IDs by default, visible progress and status, actionable errors.
- All guidance rewritten in English, with a glossary for Chinese replies.
